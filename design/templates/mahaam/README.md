# Mahaam landing template (English, desktop 1440)

Final approved design from the claude.ai design canvas (artboard "Mahaam v6").
Mahaam is a fictional AI task-assistant brand used to showcase Fasla.

## Files
- `mahaam-landing.dc.html`: the full page. Markup, inline styles, helmet CSS (keyframes, classes) and the motion logic (the `<script type="text/x-dc">` class) are all here. Treat it as the spec: structure, copy, spacing, colours and timings.
- `img/`: every image the page uses.

## Sections, in order
1. Navbar
2. Hero: text left; right a painting panel with a white "Thursday" day-planner window (voice note types, three task blocks drop into time slots, red now-line).
3. Logo marquee (10 invented logos, infinite scroll, pauses on hover)
4. "From voice to done.": 3 feature cards side by side (languages stack with flags, hand-off with animated cursor and dropdown, recap that writes itself)
5. "Ask anything you've ever said.": two rows of memory cards scrolling in opposite directions, ask box in the centre that types a question and expands an answer with numbered sources
6. Banner: outline only, no fill, pulsing rings
7. Testimonials: stacked colourful cards (orange, sage, lavender) that rotate every ~6.5 s, arrows and dots
8. Plans: monthly/yearly toggle; Free and Team beige, Pro dark (prices are placeholders)
9. FAQ: accordion, one open at a time
10. Footer with giant faint wordmark

## Type and colour
- Headings: Newsreader (serif, 400/500, italic used for accent lines). UI and body: Geist. Arabic snippet in the languages card: Cairo.
- Ink #16161A, muted #45454B / #6B6B72, beige surface #F4F2ED, brand red #E40017 (recording dot, high priority, now-line only).
