# Hero photo credits

These photos were exported from the Fasla Figma file (Hero component set `46552:249264`, page “Hero - 50 Blocks”). They are used in the docs site and Storybook examples only, with two short demo videos made from them for the Types that play video. They are **not shipped with the package**: Hero blocks take their images and videos as props.

Each photo appears once here even where several Hero Types, breakpoints and directions reuse it. The Figma file records no photographer or source link for these images.

27 files, 2.9 MB. WebP at quality 80, about 1600px on the long side (never upscaled past the Figma original); portraits only ever shown small are about 600px wide.
