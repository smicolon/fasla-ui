# Features demo photos

The Features block ships no photos, and this folder holds no image files. Its docs previews and
Storybook stories draw on photos that are already committed for other blocks. Each file's source
and credit is in the CREDITS.md of its own folder: `hero/`, `blog-cards/`, `gallery/` and `about/`
(the Hero folder records no photographer, as its Figma file does not).

Figma's Features set shows photos the code does not have, and the file does not record where they
came from. The slots below take the closest committed photo to each slot's subject and mood, so a
block in Storybook never shows a photo that was not credited. The Figma set is to be synced to
these same photos once the code is reviewed. A photo that appears in more than one Type is
repeated across Types, never inside one.

In the Hero, Blog Cards and Perforated slots, some of Figma's own photos are the committed ones
(matched by their image hash): the Portrait Photo Cards use four Blog Cards photos, and the
Perforated Photo Strip uses seven Hero and Blog Cards photos.
